Protocol, display precision and checkpoint provenance

Full-volume predictions use exhaustive 192³ windows, stride 96 with boundary coverage, and Gaussian probability blending before thresholding. Full-volume refinement uses the original frozen nnInteractive native AutoZoom engine, prompted only by the student mask. The raw-window view instead refines each 192³ window independently; these refined windows are not blended into the displayed full-volume result. Raw-window and interactive-support predictions are recorded with four supports.

All slices and binary masks retain the supplied voxel grid. CT intensities are quantized to 8 bits for display using one shared percentile window; this does not change inference. Surfaces use a three-voxel tessellation step and may omit thin structures; inspect the exact mask slices for detail. Geometry is in voxel units, with stored D/H/W axes, not verified patient orientation or physical spacing. Query references are display/scoring only. Exact dense support prompts make support predictions a diagnostic, not a test of interactive generalization.

These are interim checkpoints on one development volume, not a controlled final ranking. Both student and refined results are shown, including deterioration. No inference or network request is performed by this offline viewer.
